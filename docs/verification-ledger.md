## Update Contract

- New evidence must include the exact command or bounded method, observed result, environment, date, revision, and limitations.
- A test name is not evidence that it ran. A historical claim without an executable command or sufficiently exact recorded method belongs in [project-state.md](project-state.md), not here.
- Never convert local, fake, single-scenario, or unit evidence into scale, benchmark, security-certification, reliability, or production claims.
